## 최근 보완/재평가 항목

- **2026-11-12, [01-01 GPU 컴퓨팅 기초](records/01-01.md):** 설명력 3/3, 적용력 3/3 (시나리오 기반). 실제 GPU 실습 없음. CPU 전처리·스토리지·PCIe·GPU 실행시간의 구분 및 처리 단계 중첩은 향후 실기에서 검증.
- **2026-11-12, 01-02 진행 중:** GPU 별도 과금 항목, 쿼터와 AZ 용량 차이, VRAM 및 작업 공정성 시나리오 학습. 실제 계정 서울 리전 Standard 한도 16 vCPU, G/VT 한도 0 vCPU, 8 vCPU 증액 요청 CASE_OPENED, g6.xlarge 지원 AZ 2a/2c/2d 확인. 실제 GPU 구동·비용/예산·삭제 계획은 미검증. 모델은 E4B QAT W4A16 단일 선택. 실습/점수는 아직 완료로 기록하지 않음.
- **2026-11-12, 01-03 시작:** NVIDIA Driver, CUDA Runtime/Toolkit, 프레임워크 개념 학습 중. GPU 실습은 쿼터 승인 후 수행.
- **2026-11-12, [01-03 이론 평가](records/01-03.md):** 설명력 2/3, 시나리오 적용력 2/3. 호스트/컨테이너/Device Plugin 계층 구분은 이해. 실제 GPU 검증 대기.
- **2026-11-12, 01-04 시작:** Gemma 4 E4B QAT W4A16 + vLLM 추론 개념 학습; 실제 G1 검증 대기.
- **2026-11-12, [01-04 이론 평가](records/01-04.md):** 설명력 3/3, 시나리오 적용력 3/3. Prefill/Decode, KV Cache, CPU RAM과 VRAM, 추론 처리량 병목 분석. 실제 Gemma 추론 및 지표 실측 대기.
