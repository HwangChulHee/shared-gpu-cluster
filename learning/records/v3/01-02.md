## 실제 사용자 AWS CLI 조회 출력에 근거한 검증

- Running On-Demand G and VT quota: 8 vCPU, 코드 L-DB2E81BA
- g6.xlarge 제공 AZ: ap-northeast-2a, ap-northeast-2c, ap-northeast-2d (현재 Capacity는 미검증)
- Linux On-Demand g6.xlarge: USD $0.9896 / instance-hour
- gp3: APN2-EBS:VolumeUsage.gp3 = USD $0.0912 / GB-month
- gp3: APN2-EBS:VolumeP-IOPS.gp3 = USD $0.0057 / 추가 provisioned IOPS-month
- gp3: APN2-EBS:VolumeP-Throughput.gp3 = USD $0.0456 / 추가 provisioned MiBps-month

조회 방법: `aws pricing get-products --service-code AmazonEC2 --region us-east-1 --filters ... --query PriceList --output json` 후 PowerShell에서 각 PriceList 문자열을 `ConvertFrom-Json`하여 `priceDimensions` 출력. 첫 시도 `PriceList[0]`는 첫 항목(추가 IOPS)만 출력; 단순 `$product = $_`는 문자열 객체를 파싱하지 못해 미출력; 수정 후 gp3 3종 확인.

## 추정 견적 (AWS 실행 결과 아님)

- 가정: G1 EC2 1대/4시간, gp3 100GiB/4시간, IPv4 1개/4시간, gp3 기본 성능 이하, 730시간/월 환산
- EC2: $3.9584, gp3: 약 $0.04997, IPv4: $0.0200 → 약 **$4.0284**
- Public IPv4 $0.005/IP-hour는 AWS 공개 요금 기준이며, 이 기록의 직접 Pricing API 조회 증거는 아님.
- S3/전송량/다른 네트워크 리소스/세금 제외. EBS가 4시간보다 오래 유지되면 비용 증가.

## 콘솔 구축 준비 증거 — 보안 그룹 (2026-11-13)

사용자 제공 AWS EC2 콘솔 스크린샷에서 `g1-gpu-sg` (ID `sg-068b26f9c4bcd2506`, VPC `vpc-0b0a17f2073434255`) 생성 및 인바운드 SSH TCP 22 / `0.0.0.0/0` 규칙 확인. 아웃바운드는 규칙 1개 존재만 확인되며 세부 조건 미확인. SSH 전체 공개는 사용자가 선택한 실습용 설정으로 보안 위험을 인지하고 향후 정리 필요. 실제 GPU EC2 인스턴스는 아직 실행하지 않음.

사용자 AWS CLI `describe-images` 실제 출력에서 `ami-09f8bcda889936293`는 Canonical Ubuntu 26.04 amd64(`x86_64`)로 확인했으며, 24.04 LTS 후보는 아직 조회·선정 전.

## EC2 IAM Role 생성 증거 — 2026-11-13

사용자 제공 IAM 콘솔 스크린샷에서 `g1-gpu-ec2-role` 생성 성공 확인. Role ARN `arn:aws:iam::351889159717:role/g1-gpu-ec2-role`, Instance Profile ARN `arn:aws:iam::351889159717:instance-profile/g1-gpu-ec2-role`; 화면상 연결된 권한 정책 0개. Trust Policy는 2026-11-13 사용자 AWS CLI `aws iam get-role --role-name g1-gpu-ec2-role --query Role.AssumeRolePolicyDocument --output json` 출력으로 검증: `Effect=Allow`, `Principal.Service=ec2.amazonaws.com`, `Action=sts:AssumeRole`. S3 최소 권한 정책은 아직 미부여. 이 단계에서 GPU EC2는 실행하지 않음.
