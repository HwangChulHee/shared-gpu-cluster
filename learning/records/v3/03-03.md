- 실제 G1 GPU 측정: 아직 없음

## 이론 진행

- GPU Util과 실제 images/sec는 다르며, Batch 크기·DataLoader 대기시간·GPU 연산시간을 각각 구분함.
- Workers 0/2/4와 Batch 4/8/16을 비교할 때 한 번에 한 변수를 변경하고 CPU·디스크 경쟁, VRAM OOM을 함께 관측할 계획.
- SM Active·DRAM Active는 연산 성능 또는 대역폭 달성률 그 자체가 아니며, Warp/SM·Latency Hiding·Memory Coalescing을 학습함.
- 추가 심화 질문은 중단하고 실제 Benchmark 준비 중심으로 전환함.

## 데이터셋 준비 — 사용자 실행 결과

- 원본 COCO 2017 공개 S3 경로에서 `val2017.zip`과 `annotations_trainval2017.zip` 다운로드 성공 (`--no-sign-request`).
- `python3 -m zipfile -t`로 두 ZIP 모두 `Done testing` 확인.
- `python3 scripts/prepare-coco-benchmark.py --images-zip datasets/coco-source/val2017.zip --annotations-zip datasets/coco-source/annotations_trainval2017.zip --count 1000 --val-count 100 --seed 42` 실행 성공.
- 사용자 출력: `Created .../datasets/coco2017-benchmark: train=900, val=100`.
- 확인: Train 이미지 900·Val 이미지 100·Train 라벨 900·Val 라벨 100, 총 `du -sh` 159M.
- `manifest.json` SHA256: `d32043c943b61928ddd5c328061e99c1a9b6a100cb3f4ecd693074f4d9922677` (생성 스크립트 출력과 `sha256sum` 일치).
- **검증 범위:** 데이터 추출·파일 수·manifest 해시. 실제 YOLO 데이터 로딩·학습·S3 업로드·GPU 실행은 **미검증**.
- COCO 원래 val2017을 재분할했으므로 **성능 벤치마크 전용**이며 독립된 모델 품질 평가용이 아님.
