# Lab 01-02 — GPU 용량·쿼터·비용

> **새 21 Lab 커리큘럼의 교안 / 실측 전** · 환경: L/O. 이전 29 Lab에서 같은 번호를 사용했다면 [이관표](../migration-2026-11-13.md)를 우선 확인한다.

## 왜 배우는가

GPU EC2 사용 가능 여부는 인스턴스 지원 AZ, 계정 GPU vCPU 쿼터, 실제 남은 용량, 비용을 별도로 확인해야 한다.

## 선행 개념·내부 동작

GPU vCPU 쿼터 확인→인스턴스 사양·온디맨드 단가→EKS/CPU 노드/네트워크 비용→삭제 계획.

## 실제 운영 맥락·작업 예시

서울 리전 On-Demand G/VT **8 vCPU 승인·실제 적용 확인**. `g6.xlarge`의 인스턴스 타입 제공 AZ는 **ap-northeast-2a/2c/2d**로 확인했고, AWS Pricing API로 서울 Linux On-Demand EC2 컴퓨팅 단가 **$0.9896/시간**을 직접 확인했다. 이는 인스턴스 타입 제공 여부와 가격 증거이며 **현재 남아 있는 실제 AZ Capacity를 보장하지 않는다**.

## 실제 AWS Pricing API 검증 (2026-11-13)

Windows PowerShell에서 `aws pricing get-products --region us-east-1 --service-code AmazonEC2`로 `location=Asia Pacific (Seoul)`, `volumeApiName=gp3`를 필터링한 사용자 실제 출력:

| UsageType | 단가 (USD) | 기준 |
|---|---:|---|
| `APN2-EBS:VolumeUsage.gp3` | $0.0912 | GB-month |
| `APN2-EBS:VolumeP-IOPS.gp3` | $0.0057 | provisioned IOPS-month |
| `APN2-EBS:VolumeP-Throughput.gp3` | $0.0456 | provisioned MiBps-month |

기본 제공 성능은 3,000 IOPS / 125 MiB/s이며, 위 성능 단가는 기본 제공치를 초과하여 프로비저닝한 부분에 적용한다. 실습 견적 예시: EC2 1대 4시간 × $0.9896 = $3.9584; gp3 100GiB 4시간 × $0.0912/730h ≈ $0.04997; Public IPv4 1개 4시간 × $0.005 = $0.02; **합계 약 $4.0284**(S3·데이터 전송·기타 부가 요금·세금 제외). 여기서 100GiB, 4시간, 730h/월, IPv4 1개는 **견적 가정**이며 실제 생성/사용 증거가 아니다. EBS 볼륨이 EC2 이후에도 남으면 별도 비용이 지속된다.

## 실습 준비 (GPU 비용 발생 여부)

- 실행 환경: **L/O**. `L`은 로컬/이론, `G1`은 단일 GPU EC2, `G2`는 EKS GPU Worker 2대, `O`는 오프라인 기록·분석을 의미한다.
- G1/G2는 **AWS 계정 GPU 쿼터 승인·AZ 용량 확인 후**, 인스턴스·EKS·EBS·NAT 등의 비용 및 자원 삭제 계획을 검토한 다음에만 수행한다.
- 사용할 AMI·컨테이너 이미지·CUDA·YOLO·데이터셋의 버전, GPU 종류, Batch/Epoch, seed를 실제 실행 시 고정한다. 명령/출력은 실행 시점 실제 환경으로 검증한다.
- 관련 근거: [공식 자료 또는 실제 사례](https://docs.aws.amazon.com/ec2/latest/instancetypes/ec2-instance-regions.html) (이 링크가 실제 장애의 발생을 증명하는 자료인지, 실험 또는 일반 가이드인지 유형을 구분한다).

## 직접 해볼 Lab

1. **사전 분석:** 예상 동작과 실패 가능 계층을 글과 경로도로 정리한다.
2. **구성·실행:** 서울 리전 On-Demand G/VT 8 vCPU의 승인·적용, `g6.xlarge` 제공 AZ 2a/2c/2d, Linux On-Demand EC2 단가 $0.9896/h까지 확인되었다. **G1 단일 GPU EC2와 G2 GPU Worker 두 대의 비용을 별도로 계산**하고 실제 EC2 Capacity와 AMI/CPU/RAM 요구사항을 확인한다.
3. **실행 전 점검:** G1용 GPU 인스턴스 사양, AMI·Driver 포함 여부, GPU/CPU/RAM, Terraform plan, 실습시간·종료 명령을 확인한다. 이 Lab에서는 GPU를 실행하지 않는다.
4. **비용 검증:** GPU EC2·EBS·IPv4·S3·데이터 전송과, G2의 EKS Control Plane·CPU Node·NAT 등 별도 부대 비용을 구분한다.
5. **종료 계획:** G1 Terraform apply/destroy 경로, 증거·데이터 보존 위치, 과금 가능 잔여 리소스 목록을 문서화한다.

## 완료 증거

8 vCPU 적용 확인 로그(확보), `g6.xlarge` 제공 AZ 2a/2c/2d 확인(확보), AWS Pricing API 서울 Linux On-Demand **$0.9896/h** 및 gp3 **$0.0912/GB-month, 추가 IOPS $0.0057/IOPS-month, 추가 Throughput $0.0456/MiBps-month** 확인(확보), **G1 Terraform plan 또는 코드**, G1/G2 개별 예상 비용과 삭제 체크리스트. **GPU 실측은 이 Lab의 완료 조건이 아니다**.

**이 Lab은 GPU 실행 이전의 설계·쿼터·비용 게이트 Lab**이므로 GPU 인스턴스를 실제로 켜지 않고도 완료할 수 있다. 승인된 쿼터(8 vCPU), 인스턴스 타입 제공 AZ(2a/2c/2d), EC2 컴퓨팅 단가($0.9896/h)는 확인된 사실이다. 반면 실제 현재 AZ Capacity, AMI/Driver 구성, gp3 외 나머지 부가 비용 및 용량 확정, Terraform plan은 아직 별도 확인 증거가 필요하다.
