# Lab 07-01 — Terraform 재현·비용 정리

> **새 7 Phase / 21 Lab 교안, 미실측** · 환경: L+G1/G2/O. 이전 Lab 기록 이관은 [이관표](../migration-2026-11-13.md) 참조.

## GPU 비용 최적화 실행 구간

> 공통 기준: [GPU 실행 게이트·G1/G2 런북](../gpu-execution-gates.md). **OFF 준비를 GPU 실측 완료로 간주하지 않는다.**

| 구간 | 수행할 작업·완료 기준 |
|---|---|
| **GPU OFF-1 · 사전 학습/로컬 검증** | G1 최초 콘솔 구성·삭제 체크리스트, Terraform fmt/validate/plan과 state·destroy 영향 사전 검증; G2 IaC 분리 |
| **GPU ON · 최소 시간 실측** | G1 콘솔 최초 구축·수동 삭제 후 별도 짧은 Terraform 재현 apply/destroy 검증; G2도 별도 세션에서 삭제 |
| **GPU OFF-2 · 분석/기록** | Terraform/콘솔 생성·종료 증거, 잔여 과금·실제 비용 비교 |

GPU가 필요한 실측은 사전에 준비한 명령·성공 기준·보존 경로에 따라 실행한다. 실패하면 진단 시간·비용 상한을 적용하고 후속 실험을 멈춘다.

## 학습 목표와 실제 운영 맥락

IaC 상태·버전·데이터·리소스 삭제가 통제되어야 운영 실험을 재현할 수 있다.

## 내부 동작

Terraform plan→apply→GPU 검증→결과 보존→destroy→과금 확인.

## 구체적 작업 예시

G1 단일 Linux GPU 인프라와 G2 EKS GPU 클러스터를 **별도 비용 세션**으로 각각 생성·재현·삭제한다.

## 실습 전 준비

- 실행 환경 L+G1/G2/O; G1/G2 포함 시 GPU 쿼터/AZ/AMI/가격과 EKS·CPU 노드·NAT·EBS·S3 과금 및 삭제 계획 점검.
- 사용한 Terraform·GPU 드라이버·컨테이너·YOLO·입력 데이터 버전 고정.
- 자연 발생 사고가 아닌 조작된 실험은 장애 주입이라고 기록.

## 단계별 실습

1. **G1 Terraform 설계는 Lab 01-02에서 이미 준비**, G2 Terraform은 Lab 04-01/04-02에서 검증한 코드를 재사용한다. G1/G2의 생성·삭제와 실제 비용을 각각 기록한다.
2. G1과 G2를 **각각 별도 세션**으로 생성·검증·삭제하고, 가능하면 작은 변경/재실행 검증을 한다. 실측된 절차만 재현 완료로 표기한다.
3. Terraform state 보존/보안·버전 고정, data/체크포인트/메트릭 외부 보존, 각 세션의 작업·노드·GPU·CPU·스토리지 기록을 확인한다.
4. 반복 가능한 정상 기준선과 결과를 비교해 원인·한계 설명.
5. 증거 외부 보존 후 실제 비용 리소스 정리.

## 완료 증거

Terraform/버전/비용/실제 잔여 리소스 점검.

실제 수행 전에는 완료로 기재하지 않는다. [관련 자료](https://developer.hashicorp.com/terraform/docs).
