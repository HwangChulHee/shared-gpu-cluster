# Lab 01-03 — NVIDIA 소프트웨어 스택과 YOLO

> 새 21 Lab · **이전 01-03 GPU 스택 + 01-05 YOLO 이론 통합** · 현재 기존 이론 일부 이수 / G1 실습 대기.
>
> 기존 사용자 서술형 평가는 [구 01-03 기록](../../learning/records/01-03.md) 및 [구 01-05 기록](../../learning/records/01-05.md)에서 확인한다. 새 통합 Lab은 실습까지 검증한 뒤 별도 완료 판정.

## 왜 배우는가

AI/GPU 인프라의 기본기는 **호스트가 GPU를 인식하는 것 → 컨테이너에 GPU를 노출하는 것 → PyTorch CUDA 연산 → 실제 YOLO 학습**을 구분하고 각각 확인하는 것이다. 이 중 한 단계만 성공한 상태는 전체 성공이 아니다.

## 계층 구조

`GPU 장치 → 호스트 NVIDIA Driver → NVML/nvidia-smi → Container Runtime·NVIDIA Container Toolkit → 컨테이너 CUDA Runtime/PyTorch → YOLO Forward/Backward/Optimizer`

- 호스트에 CUDA Toolkit 전체가 설치되어 있지 않아도 호스트 Driver가 적절하고 컨테이너에 필요한 라이브러리가 있으면 CUDA 프로그램 실행이 가능하다.
- 호스트 `nvidia-smi` 성공이 컨테이너 GPU 사용 가능·PyTorch CUDA 연산 성공을 보장하지 않는다.
- 단일 GPU EC2에서 Docker 실행에는 Kubernetes NVIDIA Device Plugin이 필요하지 않다. 이는 [02-03 GPU 등록](../labs/02-03.md)에서 다룬다.
- YOLO 학습 시 모델·Optimizer·Gradient·Activation은 각기 GPU 메모리에 영향을 준다. Batch/Gradient Accumulation/Checkpoint는 이전 YOLO 이론에서 이미 학습한 부분만 재활용한다.

## 실습 전 준비 (GPU 비용 없음)

1. 사용할 GPU 인스턴스 후보·AMI·Driver·컨테이너 이미지·PyTorch/YOLO·데이터셋의 지원 버전 및 라이선스 검토.
2. 정상 신호 표 작성: (a) GPU 장치, (b) 호스트 `nvidia-smi`, (c) GPU 컨테이너 `nvidia-smi`, (d) `torch.cuda.is_available()`와 실제 텐서 연산, (e) 짧은 YOLO 학습 성공.
3. GPU 계열 EC2 쿼터 승인/AZ 사용 가능 여부, 단가·예산·인스턴스 삭제/잔여 비용을 확인하기 전에는 유료 GPU를 가동하지 않는다.

## G1 실습 (쿼터 승인 후)

1. **호스트 (GPU EC2):** `nvidia-smi`, `nvidia-smi --query-gpu=name,driver_version,memory.total --format=csv`로 GPU/Driver 상태 기록.
2. **컨테이너 검증:** 선택한 Driver 버전과 호환되는, 실제로 확인된 CUDA 이미지로 `docker run --rm --gpus all <검증된-이미지> nvidia-smi` 실행. 꺾쇠 인수는 설명용 자리표시자이며 그대로 실행하지 않는다.
3. **PyTorch 검증:** CUDA 사용 가능 여부와 실제 GPU 텐서 계산 수행. CPU 전용 PyTorch 설치나 Driver/CUDA 지원 범위 문제를 분리한다.
4. **YOLO 검증:** 공개 소형 데이터셋, 작은 Batch/Epoch으로 모델 학습. 이미지/모델 버전, 학습 결과, GPU VRAM 최고 사용량, CPU RAM, 실행시간 기록.
5. **검증·정리:** 호스트/컨테이너/프레임워크/YOLO 네 계층을 각각 성공·실패 증거로 구분. 데이터를 보존하고 GPU 인스턴스를 종료·삭제 후 과금 확인.

## 장애 판단 사고실험

호스트 `nvidia-smi`가 정상인데 컨테이너 `nvidia-smi`가 실패한다면 호스트 Driver를 재설치하기 전에 Toolkit·런타임 통합·실행 옵션을 확인한다. 컨테이너는 정상이지만 PyTorch CUDA가 실패하면 프레임워크 빌드·Driver 호환성·GPU 장치 노출 상태를 확인한다.
