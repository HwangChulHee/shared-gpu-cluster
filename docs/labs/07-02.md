# Lab 07-02 — 운영 보고서·RCA·최종 시연

> **새 7 Phase / 21 Lab 교안, 미실측** · 환경: O. 이전 Lab 기록 이관은 [이관표](../migration-2026-11-12.md) 참조.

## 학습 목표와 실제 운영 맥락

실제 관측과 가설, 반복 조건, 실패, 한계를 구분해 제3자가 재현 가능하게 한다.

## 내부 동작

설계→정상 기준선→성능·장애 실험→비교→RCA/Runbook.

## 구체적 작업 예시

인프라·YOLO 학습·GPU/Job 메트릭·실험 로그를 연결하여 시연한다.

## 실습 전 준비

- 실행 환경 O; G1/G2 포함 시 GPU 쿼터/AZ/AMI/가격과 EKS·CPU 노드·NAT·EBS·S3 과금 및 삭제 계획 점검.
- 사용한 Terraform·GPU 드라이버·컨테이너·YOLO·입력 데이터 버전 고정.
- 자연 발생 사고가 아닌 조작된 실험은 장애 주입이라고 기록.

## 단계별 실습

1. 가설, 기대 결과와 반증 조건을 문서화.
2. 인프라·YOLO 학습·GPU/Job 메트릭·실험 로그를 연결하여 시연한다.
3. 작업·노드·GPU·CPU·스토리지 로그/메트릭 및 시간 기록.
4. 반복 가능한 정상 기준선과 결과를 비교해 원인·한계 설명.
5. 증거 외부 보존 후 실제 비용 리소스 정리.

## 완료 증거

README 설계 근거·실측 결과·Runbook·재현 절차·비용·미구현 범위.
