# Lab 03-03 — Kueue 큐·공정성 비교

> **학습 교안 / 미실행**. 실행 절차는 실제 AWS/패키지 버전에 맞춰 고정한 뒤 수행합니다. 예상 결과는 실측 결과가 아닙니다.

## 학습 맥락과 목표

작업이 대기 중일 때 Kueue가 아직 승인하지 않은 것인지, 이미 승인했으나 Scheduler가 GPU 노드를 찾지 못하는 것인지에 따라 진단 방법이 달라진다.

## 핵심 개념·원리

1. Kueue는 Kubernetes Scheduler를 대체하지 않는다. Job을 승인(admission)하기 전에 큐·할당량 정책을 적용하며, 승인된 작업의 Pod 배치는 기본 Scheduler가 수행한다.

2. ClusterQueue는 자원 묶음과 할당량 정책을, LocalQueue는 사용자가 작업을 제출하는 네임스페이스 큐를 표현한다. Workload 객체의 admission 상태와 Job suspend 상태를 함께 확인한다.

3. Quota borrowing은 다른 큐에서 사용하지 않는 자원을 대여할 수 있게 한다. 다만 모든 부서의 대기 시간을 자동으로 같게 만드는 마법 같은 기능은 아니며, 정책·선점·우선순위 효과를 측정해야 한다.

## 내부 흐름

Job 제출 → LocalQueue/Workload 생성 → ClusterQueue 할당량 확인 → Kueue admission 승인/보류 → Job unsuspend → Pod 생성 → Kubernetes Scheduler 배치 → 완료 후 Quota 반환.

## 실습 준비

기본 Kubernetes 스케줄링(T02) 기준선의 동일한 모델/작업 길이/제출 패턴 확보.

## 실습

1. 기본 스케줄링에서 세 부서의 Job 대기·실행시간을 기록.
2. Kueue 및 ClusterQueue/LocalQueue를 설치하고 Workload admission/Job suspension를 관측.
3. 같은 패턴을 반복하고 quota borrowing을 켰을 때 자원 이용과 부서별 대기시간이 어떻게 달라지는지 비교.

## 검증할 증거

- 도입 전후 공정성·처리량·대기시간 비교 표 작성

## 실습 확장: Kueue 상태와 최소 설정 요소

Kueue 실습은 **설치 → 기본 Queue → Job admission → 자원 부족 시 대기 → 자원 반환 → borrowing 비교** 순으로 수행한다. 정확한 매니페스트 API 버전과 지원되는 `ResourceFlavor`, `ClusterQueue`, `LocalQueue` 필드는 **실습 시점의 설치한 Kueue 버전 공식 예제**를 사용한다. 버전 확인 전 임의 YAML을 적용하지 않는다.

- `ResourceFlavor`: 사용할 노드/자원 유형을 이름으로 표현하고 필요 시 노드 레이블 등의 제약을 구성한다.
- `ClusterQueue`: ResourceFlavor별 GPU 할당량과 팀 간 공유·borrowing 정책을 관리한다.
- `LocalQueue`: Namespace 내 Job이 제출되는 큐.
- `Workload` admission: 큐 단계에서 **승인 전 대기**, Job suspension 상태와 함께 확인.
- `Pod Pending`: Job이 unsuspend되어 Pod가 생성된 **후** Scheduler 배치 실패 여부 판단.

```bash
kubectl get clusterqueues
kubectl get localqueues -A
kubectl get workloads -A
kubectl describe workload -n <TEAM-NS> <WORKLOAD-NAME>
kubectl describe pod -n <TEAM-NS> <POD-NAME>
```

**실험 조건:** 같은 GPU 2개, 같은 세 팀 제출 순서, 같은 Job 실행시간을 유지한다. 기본 정책과 Kueue 설치 후의 **admission 대기시간, Pod Pending 시간, 실행시간**을 별도로 기록한다. borrowing이 유효하려면 두 개 이상의 관련 ClusterQueue 및 cohort 구성 등 대여 가능한 설계를 마련해야 하며, 단일 큐만 만든 뒤 borrowing 효과를 기대하지 않는다.
